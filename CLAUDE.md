# CLAUDE.md

Bas Gaza: a 2D phone browser game for Turkish driving licence (e-sınav) practice. See `PRODUCT.md` for what we are building and the build order.

## Working with Sude

- Sude is new to software projects. Write to her in Turkish, in plain words.
- Code, comments, file contents and commit messages are in English. Text shown to players in the game is in Turkish.
- When Sude has to do something herself, give exact steps, one at a time.
- Work in small steps. Each step in `PRODUCT.md` ends with something she can play on her phone.
- Propose a plan and wait for her approval before choosing a framework, a library or hosting.
- This project is separate from `~/Desktop/App` (Clocked). Never touch that folder.

## Content rules

- Questions, answers and explanations come only from the content file in this project, based on official material. Never generate or invent them, and never fill gaps with your own knowledge.
- First aid content must be exactly right. If a source is unclear or sources disagree, leave the question out.
- Do not copy copyrighted question banks word for word. Write questions in our own words from official facts, and record the source of each one.
- Draw traffic signs, warning lights and other pictures ourselves (SVG). Do not copy images from other apps or sites.

## Product rules

- The game must be original, not a copy of an existing game.
- Version 1 is a static web app only: no AI model API, no server, no accounts.
- Keep the "Not in version 1" list in `PRODUCT.md`. Do not build those things unless Sude asks.
